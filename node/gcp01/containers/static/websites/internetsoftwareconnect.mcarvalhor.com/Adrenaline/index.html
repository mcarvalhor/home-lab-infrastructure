Adrenaline

Como Usar

Para usar o Adrenaline, basta baixar o programa e abrir normalmente:

  • Baixe o arquivo para seu computador:
  • Baixar/Download
  • O arquivo deve começar a ser baixado em breve... Baixar de novo
  • Abra o arquivo baixado.
  • Se aparecer alguma notificação de seu anti-vírus, você pode ignorar e permitir que o Adrenaline seja executado. Não se preocupe, o programa não é vírus. Acontece que ele não é muito baixado, sendo assim muitos anti-vírus desconfiam dele. Eu sou um usuário muito avançado.
  • Se você marcar "Exibir opções", você pode definir as configurações do temporizador (se desejável).
  • Clique em "Iniciar". Certifique-se de não bloquear o seu computador manualmente.
  • Pronto! O Adrenaline já está em execução.
